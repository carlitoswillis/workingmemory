# Working Memory on the phone â its own app

## 1. Design thesis (10 lines)

1. The phone app is an **instrument**, not an editor: you open it to see what's on your mind *now*, tick a daily card, and drop a thought.
2. Its unit is the **row**, not the card-in-a-column. Columns are a desktop spatial metaphor; a thumb has one axis.
3. Opening must paint **before the network** â cached shell + last-known board, reconciled after (web.dev app-shell).
4. Completion is **one tap, zero dialogs, optimistic**, with the write to Supabase invisible behind it.
5. Satisfaction is **restraint**: a 140ms spring overshoot on the check, a luminance step, a streak number ticking up. No confetti, no glow.
6. It is **NOT** a board editor: no column create/delete/rename, no cross-board bulk moves, no dnd choreography as a headline feature. Those stay on desktop.
7. It is **NOT** the desktop layout at 375px. The five columns become one Now feed plus one paged Lists screen.
8. Everything reachable in the **bottom third**; the top is orientation only (Hoober thumb-zone).
9. The **iOS Home-Screen install is the runtime**. Standalone chrome, safe areas, Web Push. Safari-in-a-tab is the fallback, not the target.
10. Shares the data model, server actions, board context, and Nocturne tokens with desktop. Shares no layout.

## 3. The completion moment

**Taps from cold open: 1.** App opens on Now; the recurring cards for today are the first section below the header.

1. Finger lands anywhere in the row's leading 44Ã44 zone (visual glyph stays 18px; the hit area is padding â HIG 44pt, WCAG 2.5.8 floor 24px).
2. **Same frame, in the same handler, before any `await`:** local state flips â glyph fills via SVG `stroke-dashoffset` + scale spring `0 â 1.08 â 1` (damping ~18, stiffness ~320, settles â140ms); row's surface steps one luminance level and text drops to secondary; streak number increments with `font-variant-numeric: tabular-nums`.
3. **Haptic, best-effort, never load-bearing:** `navigator.vibrate(8)` where supported (Android); on iOS, `label.click()` on a visually hidden `<input type="checkbox" switch>` (Safari 17.4+; patched in iOS 26.5 â wrap in try/catch, feature-detect, silently no-op).
4. **Then** fire the server action: repeating cards â `setDailyDoneAction(boardId, id, localToday())`; `recurrence:'none'` â `toggleDoneAction`. Never block UI on it.
5. After 900ms the row collapses (height+opacity, 180ms) into `Done today`. An inline **Undo** sits in the row for those 900ms; failure pins a persistent error state *on the row* â never a toast.
6. Milestones only (7/30/100): a single 400ms color pulse on the streak number. Nothing on ordinary days (Freiberg: animation fatigue on high-frequency, low-novelty actions).

No confirmation dialog, ever. No spinner. Sound: **out of scope** (critic-discounted).

Sources: Freiberg *Invisible Details of Interaction Design*; Apple HIG; WCAG 2.5.8; Streaks (state-of-icon, not strikethrough); tijnjh/ios-haptics.

## 5. Touch rules

- **Reorder = long-press only.** New phone sensor config: `TouchSensor { delay: 250, tolerance: 5 }`. Vertical scroll of a long Backlog must never be stolen by the first pixel.
- **`touch-action`:** `pan-y` on list scrollers, `pan-x` on the Lists pager track, `none` applied to the active draggable only, at drag start.
- **Swipe on a row:** right = complete (redundant with the tap, never the only path), left = reveal Snooze/Archive buttons. Directional lock: commit only if `|dx| > 10 && |dx| > 2*|dy|` within the first 15px; hit-test starts **â¥28px inset from both screen edges** so it never races iOS back-swipe. Disabled while a long-press drag is armed.
- **Nesting-by-hover-hold is off on phone.** Move a card via the card sheet's "Move toâ¦" list. A 550ms still-hold is not a fingertip gesture.
- Auto-scroll on drag: `AutoScroller.configure({ threshold: { x: 0, y: 0.2 } })`.
- `-webkit-tap-highlight-color: transparent` globally; all `:hover` rules wrapped in `@media (hover: hover) and (pointer: fine)`; `:active { transform: scale(0.985) }` as the real touch feedback.
- **Do not touch `SwipeToArchive.tsx`** â its CLAIM_MS/SLOP constants are tuned against the desktop board's sensor. Phone rows get their own swipe implementation inside `PhoneRow.tsx`.

## 6. Motion tokens (`components/phone/phone-motion.ts`)

```ts

  tapScale:   { duration: 90,  ease: 'cubic-bezier(.2,0,.2,1)' }, // :active press
  check:      { type:'spring', stiffness: 320, damping: 18 },     // ~140ms, slight overshoot
  rowCollapse:{ duration: 180, ease: 'cubic-bezier(.4,0,.2,1)' }, // height+opacity out

  sheetDrag:  { type:'spring', stiffness: 400, damping: 40 },     // gesture handoff

  milestone:  { duration: 400, ease: 'ease-out' },                // 7/30/100 only
} as const;
```

Springs only where a finger is involved (drag settle, sheet release, the check). Everything programmatic is â¤260ms ease-out (Kowalski's 43 rules; Linear's motion language). Reduced motion: rely on the existing global rule in `globals.css:308-315` (zeroes durations with `!important`, beating inline styles) â **add no per-component media queries**; for spring-driven values, read `matchMedia('(prefers-reduced-motion: reduce)')` once in `phone-motion.ts` and export `M` with springs swapped for `{duration: 1}`.

## 8. Accessibility, typography, density

- **Type ladder** as CSS vars: title 15px/1.25, body 15px/1.4, meta 13px/1.45, caption 11px/1.5 (HIG floor 11pt). Two sizes Ã three weights (400/510/590) + a hairline divider â not five sizes.
- **Dynamic Type**, Safari-only progressive enhancement inside `@supports (-webkit-touch-callout: none)`: `font: -apple-system-body; font-family: var(--font-sans);` on row title/body. Keep the rem ladder as the universal baseline.
- Titles **clamp to 2 lines** (`-webkit-line-clamp:2`) with `min-height`, never a single-line ellipsis; rows grow, never clip, at accessibility text sizes (WCAG 1.4.10 reflow).
- Checkbox is a real `<button role="checkbox" aria-checked>` with `aria-label` = title only; state lives in `aria-checked`. Streak exposed in the accessible name: `"Gym, 12 day streak, not done today"`.
- Swipe actions are mirrored as focusable buttons in the row's overflow â swipe is a shortcut, never the only path.
- dnd-kit: custom `announcements` naming list + position ("card 2 of 5 in Focus"), `aria-roledescription="sortable card"`.
- Contrast audited in **both** palettes: text 4.5:1, non-text UI (unchecked ring, drag glyph, focus ring) 3:1. Dark base `#121212`â`#161616`, cards one luminance step up, body text ~`#E2E2E4` (87% white) â **never `#FFF` on near-black** (halation). Elevation = luminance step + hairline border, never shadow. Never remove focus outlines. `tabular-nums` on all counts.

## 10. Architecture
